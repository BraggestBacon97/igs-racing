# STEM Racing — Webseite (Turbo Lance Purple)

Kurz: Einfache, statische Website für das STEM Racing Team "Turbo Lance Purple".

Übersicht
- Öffnen: `index.html` im Browser (Doppelklick oder Datei öffnen)
- Inhalt: Statische HTML/CSS/JS-Dateien — keine Server-Komponente nötig

Wichtige Dateien
- [index.html](index.html) — Hauptseite
- [game.html](game.html) — Spiel/Experiment
- [beemovie.html](beemovie.html) — Ergänzende Seite
- `bilder/` — Bilder & Logos
- `save/` — (evtl.) Spiel-/Speicher-Dateien

Schnelländerungen
- Texte bearbeiten: Öffnen Sie `index.html` in einem Editor (z. B. VS Code)
- Bilder: Neue Dateien in `bilder/` legen und Pfade in der HTML anpassen
- Sponsoren/Links: Direkt in der HTML-Datei bearbeiten (falls vorhanden)

Deployment
- Lokal: Datei `index.html` im Browser öffnen
- Online: GitHub Pages oder Netlify sind ausreichend für statische Seiten
